相机水印

Sileo 源 · CameraWatermark 1.0.0

添加源

在 Sileo 里打开 软件源 → 编辑 → 添加，输入：

https://gh-proxy.com/https://raw.githubusercontent.com/darenni86-svg/CameraWatermark/main/docs/

刷新后搜索「相机水印」安装即可。

直接下载 deb

  • iphoneos-arm64
  • iphoneos-arm

分不清就看手机里有没有 /var/jb：有就是 rootless。

安装后

Respring，然后把「相机」从后台彻底划掉再打开，拍一张照片看看相册。
